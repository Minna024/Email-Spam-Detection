# Email Spam Detection

## About the Project
Email Spam Detection is a machine-learning project that classifies email messages as Spam or Not Spam.

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Streamlit

## Features
- Accepts email text from the user.
- Uses a machine-learning classification model.
- Displays a spam or not-spam prediction.
- Provides a simple web interface.

## How to Run
1. Install Python.
2. Install the required libraries using `python -m pip install -r requirements.txt`.
3. Run the application using `python -m streamlit run app.py`.
4. Open the local URL displayed in the terminal.

## Disclaimer
This is an educational project. Predictions may be inaccurate and should not be used as the sole basis for deciding whether an email is safe.
